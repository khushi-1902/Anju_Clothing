# Anju Clothing

React + Vite + Tailwind CSS e-commerce application.

## Project Structure

- `frontend/` - React frontend application (Vite, React 19, Tailwind CSS v4)
  - `frontend/src/main.tsx` - React entrypoint
  - `frontend/src/App.tsx` - Primary application component
  - `frontend/src/index.css` - Global CSS & Tailwind CSS v4 setup
  - `frontend/index.html` - HTML shell
  - `frontend/vite.config.ts` - Vite configuration
- `backend/` - Backend API services and server logic
- `database/` - Database schemas, migrations, and seed scripts

## Development

Run development server from root:
```bash
npm run dev
```

Or from frontend directory:
```bash
cd frontend
npm run dev
```
